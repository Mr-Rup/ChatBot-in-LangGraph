# ChatBot-in-LangGraph

A LangGraph based ChatBot with Streamlit frontend.

## Setup

1. Make sure you have python installed and create a virtual environment:

   ```bash
   py -3.11 venv .myenv  # version3.11 or 3.12 recomanded
   .myenv\Scripts\activate
   ```

2. Install requirements:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the Streamlit application:

   ```bash
   streamlit run frontend_streaming.py
   ```
